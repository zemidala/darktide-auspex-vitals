# Идеи

## Что умеет Healthbars (для сравнения)

По его настройкам (версия 26.08.25, около 5300 строк Lua):

- Полоса здоровья над врагами, отдельно по категориям: орда/бродяги, элита, специалисты, чудовища/капитаны, ритуалисты.
- Периодический урон со стаками или временем: кровотечение, горение, токсин, варп-огонь (Soulblaze, выбор цвета), фосфорное горение, кровотечение Chordclaw.
- Дебаффы: хрупкость брони, повышенный урон / урон в ближнем бою, электрошок, Empyric Shock, Skullcrusher, Thunderstrike, неисправность оружия.
- Ошеломление (точно — в Психаниуме, соло и у хоста; у клиентов — оценка с модом Animation Events).
- Цифры урона, отчёт DPS, подпись с именем врага / типом брони.
- Маркеры периодического урона и дебаффов на стандартных полосах боссов.
- Режимы для Психаниума, «показывать после убийства N секунд».

## Что умеет Enemies Improved (Nexus 809, для сравнения)

Автор Alfthebigheaded, версия 2.2.3, около 19 000 строк Lua (без базы анимаций), больше 200 настроек. Код не копируем, как и у Healthbars. Функции:

- Полосы здоровья с «призрачной» частью, делениями на 25/50/75 %, иконкой типа врага. Поверх полосы — стойкость, если она у врага есть.
- **Кластеры орды**: если рядом много одинаковых врагов орды, у них одна общая полоса, которая следует за группой.
- Дебаффы трёх видов: периодический урон, «служебные» (пробивание, +урон, ослабление) и состояния по ключевым словам (кровотечение, электрошок, горение). Похожие можно объединять в одну запись. Дебаффы можно показывать на теле врага, а не над головой. Отдельно: дебаффы на стандартной полосе босса вверху экрана.
- **Ошеломление** на клиенте определяется по анимациям врага: мод сопоставляет анимации ошеломления из данных пород. Blackboard у клиента нет.
- **Спецатаки** определяются по звукам (замах сетевика, вспышка снайпера, крик демонхоста и т. п.): маркер над врагом пульсирует.
- Контуры: помеченные, ошеломлённые, спецатаки, свои цвета по типу врага.
- Цифры урона (криты, слабые места), DPS после убийства.
- Фильтры: только враг под прицелом (конус прицела), только помеченные, только Психаниум. Полосы не-орды скрываются через N секунд без урона. «Показывать только последних N раненых». Орда показывается, пока на ней дебафф.
- Прозрачность: общая, при прицеливании (ADS), затухание по дальности и для врагов, закрытых другими врагами.
- «Ослабленные» боссы (спавн с уменьшенным здоровьем) — свой цвет полосы.
- Производительность: **пространственное отсечение** (приоритет по расстоянию, классу и близости к прицелу; в плотной толпе видны передние и важные), отдельная частота обновления для врагов на экране и за его пределами.
- Переопределения всего по группам и по отдельным породам; скрытие стандартных полос боссов.

Чем мы отличаемся: у него маркер ставится почти каждому врагу, а нагрузку сдерживают отсечение и редкое обновление. У нас маркеры получают только K ближайших, поэтому число виджетов ограничено сразу. И настроек у нас на порядок меньше.

**Что стоит взять (идеи, не код):**
- ~~Близость к прицелу в отборе~~ и ~~деления 25/50/75 %~~ — взяты в 0.1.
- Скрывать полосу не-орды через N секунд без урона (опция).
- Полоса стойкости поверх здоровья (у клиента есть `MinionToughnessHuskExtension`).
- Цвет «ослабленных» боссов.
- Метки периодического урона на стандартной полосе босса.
- Позже: ошеломление по анимациям, кластеры орды, фильтр «только под прицелом / только помеченные», прозрачность при прицеливании.
- Предупреждать и об Enemies Improved: при обоих модах у врагов две полосы.

## Чем можно сделать лучше (черновик, выбрать вместе)

**Понятность**
- Одна компактная «карточка» над врагом вместо набора отдельных элементов: полоса, стойкость/броня, 2–3 самых важных эффекта иконками; остальное — по наведению прицела.
- Приоритет эффектов: показывать то, что влияет на решение игрока сейчас (например, «скоро умрёт от горения» — не добивать), а не всё подряд.
- Подсветка «добьёт следующий удар» для текущего оружия (если урон можно оценить).

**Производительность**
- Обновлять маркеры не каждый кадр, а с частотой по расстоянию и видимости; лимит числа маркеров, дальние — упрощённо.
- Не создавать маркеры для орды, пока по ней не прошёл урон (режим «только раненые»).

**Настройка**
- Готовые пресеты: «Минимум», «Стандарт», «Всё» — одной кнопкой вместо десятков галочек.
- Настройки по категориям врагов в одной таблице, а не во вкладках.
- Русский язык с первого дня; английские названия в меню по умолчанию (как в `mods_ru`).

**Совместимость**
- Проверять наличие полей и методов игры перед использованием (урок Patch 1.13), чтобы обновление игры отключало функцию, а не роняло игру.
- Не конфликтовать со стандартными полосами боссов и с Healthbars (предупреждать, если стоят оба).

## Первая версия (0.1) — решено 2026-09-30

1. Полоса здоровья над врагом; категории: орда, элита, специалисты, чудовища/капитаны. Режим на категорию: «всегда» / «только раненые» / «выкл». По умолчанию орда — только раненые, остальные — всегда (в пределах дальности).
2. Компактная карточка: тонкая полоса, под ней 2–3 иконки периодического урона со стаками (горение, кровотечение, токсин, варп-огонь) по приоритету. Число HP и имя врага — опционально, по умолчанию выкл.
3. Производительность: максимальная дальность, лимит маркеров (ближние в приоритете), реже обновлять дальние.
4. Пресеты «Минимум / Стандарт / Всё» + выпадающий список режима на каждую категорию.
5. Защитные проверки полей и методов игры; предупреждение, если стоит Healthbars или Enemies Improved.
6. Из Enemies Improved: приоритет по прицелу при отборе полос (настройка, по умолчанию вкл) и деления 25/50/75 % на полосе.

7. Настройка «Скрывать индикатор урона игры» (`damage_indicator` в Психаниуме).

9. Значки периодического урона — под полосой и на ленте урона. Основной вариант — плоские значки-материалы игры в цвет эффекта (`presets/preset_20` горение, `preset_11` электрошок, `preset_13` кровотечение, `havoc_mutator_ember` варп-огонь, `havoc_mutator_nurgle` токсин): к ним же пришли Healthbars, Enemies Improved и DivisionHUD. Запасной — картинки баффов в `buff_container_with_background`, дальше — цветная метка. Всё с проверкой, что ресурс загружен. `/av_icons` — просмотр всех вариантов в игре.
8. Свои цифры урона (запрос автора): белые / жёлтые (слабое место) / оранжевые (крит), периодический урон отдельно.

Отложено: ошеломление, дебаффы, DPS, «добьёт следующий удар», метки на полосах боссов, режимы Психаниума.

## Кольцо здоровья над головой (проработка, 2026-09-30)

Вид полосы — настройка «Вид: полоса / кольцо». Зачем: в толпе широкие полосы налезают друг на друга, а кольцо компактно (30–40 пикс.) и читается как «сколько осталось» даже краем глаза.

**Как выглядит**
- Кольцо над головой (та же точка, что у полосы). Заполнено по часовой стрелке от 12 часов: оставшееся здоровье — цвет категории, «призрачный» урон — светлая дуга, потерянное — тёмная подложка.
- Деления 25/50/75 % — разрывы на 3, 6 и 9 часах.
- Внутри кольца — главный эффект: значок самого приоритетного периодического урона и число стаков. Остальные эффекты — маленькие точки-значки по нижнему краю кольца.
- Толщина и диаметр — по категории: орда тонкое и маленькое, элита и специалисты крупнее, боссы — самое большое, с двойным контуром.
- Стойкость/броня (позже) — второе тонкое кольцо снаружи.
- Число здоровья и имя — по-прежнему опционально: число под кольцом, имя над ним.
- Смерть: кольцо быстро «схлопывается» (догорает дуга), как сейчас полоса.

**Как нарисовать (оба варианта — ресурсы игры)**
1. **Сегменты из повёрнутых прямоугольников** (`pass_type = "rotated_texture"`, как штрихи прицела в `crosshair_template_*`): 24–32 коротких сегмента по окружности, каждый повёрнут по касательной. Заполнение = сколько сегментов закрашено. Плюсы: полный контроль, любой диаметр и толщина, разрывы-деления бесплатно. Минус: 24–32 прохода на маркер (при 20 маркерах ~600 проходов) — дороже полосы; для орды можно 16 сегментов.
2. **Дуговой материал игры** `content/ui/materials/effects/forcesword_bar` с параметром `arc_top_bottom` (им рисуются заряды у прицела, `weapon_counter_template_block_charges.lua`): плавная дуга с заливкой, 2–4 прохода на маркер. Минус: это дуга на одну сторону, полное кольцо — из двух зеркальных половин; форма и толщина заданы материалом, надо проверить в игре, как он выглядит мелко.

Сделано (2026-09-30): настройка «Вид здоровья: полоса / кольцо». Кольцо — 24 точки-прямоугольника без поворота (направление угла у rotated_texture по коду не проверить), зазоры между четвертями = деления. Эффекты — строкой под кольцом; значок в центре — следующий шаг.

Варианты (2026-09-30), настройка «Вид здоровья»: полоса; кольцо из точек (со «призрачным» следом); гладкое кольцо — `icons/items/salvage_circle` с `progress`, отражено по UV, чтобы урон шёл по часовой; сфера — `backgrounds/scanner/scanner_drill_circle_filled`, уровень обрезкой по UV (`texture_uv`), контур — `hud/communication_wheel/middle_circle`. Опция «Главный эффект в центре» для колец и сферы. Выбор материалов — по `/av_rings` в игре (1–3 из рамок способности в миссии не загружены).

Рекомендация: начать с варианта 1 (предсказуемо, без сюрпризов материала), вариант 2 проверить через `/av_icons`-подобный просмотр и перейти на него, если выглядит хорошо, — он дешевле.
