# Проверка в игре перед релизом

Проверяет автор. После каждого пункта — посмотреть свежий лог (`%APPDATA%\Fatshark\Darktide\console_logs`) на строки `[MOD][auspex_vitals][ERROR]` / `[WARNING]` и на `Lua->update` в `Stall`.

Отмечать `[x]`; если что-то не так — скриншот и время из лога.

## 1. Запуск и меню

- [ ] Игра запускается, в логе `[MOD][auspex_vitals][INFO] loaded`, ошибок мода нет.
- [ ] Меню модов: название и все подписи настроек на русском (язык игры ru) и на английском (en).
- [ ] Подсказки (наведение на настройку) показываются и не обрезаны.
- [ ] Пресеты «Минимум / Стандарт / Всё»: после выбора и повторного открытия меню значения ниже поменялись.
- [ ] Выключить мод галочкой — полосы и цифры исчезают; включить посреди миссии — появляются.

## 2. Психаниум (соло, ты — хост)

- [ ] Полосы над манекенами и врагами из меню спавна; орда — только раненые, остальные — всегда (Стандарт).
- [ ] Вид «Полоса» и «Сфера»: переключение применяется сразу.
- [ ] Толщина полосы 3 и 20; ширина 50 % и 200 %; сдвиг по высоте −100 и +150.
- [ ] Число здоровья: размер 50 % / 250 %, все цвета, «По здоровью» меняет цвет по мере урона.
- [ ] Вид числа «Сокращённо» на враге с HP ≥ 1000 (огрин, босс): 2.3к / 2,3к, без «.0».
- [ ] Значки периодического урона: горение, варп-огонь, кровотечение, токсин, электрошок — со стаками.
- [ ] Цифры урона: все 5 стилей, обычный / слабое место / крит разного цвета, тики эффектов.
- [ ] «Скрывать индикатор урона игры» убирает стандартную полоску Психаниума.
- [ ] Враг за стеной — полоса скрыта; за другим врагом — полупрозрачная.

## 3. Миссия соло (или частная с ботами)

- [ ] Плотная орда: полос не больше лимита, ближние / у прицела в приоритете.
- [ ] Босс (Чудовище / капитан): своя полоса, стандартная сверху скрыта (настройка вкл) и видна (выкл).
- [ ] FPS в плотной орде с модом и без (выключить галочкой) — разница записать.

## 4. Клиентом у чужого хоста (обычная публичная миссия)

- [ ] Полосы и здоровье совпадают с реальностью (враги умирают, когда полоса пустая).
- [ ] Значки периодического урона появляются и у врагов, подожжённых союзниками.
- [ ] Цифры урона — только свои, чужой урон не показывается.

## 5. Перезагрузка модов (Ctrl+Shift+R, режим разработчика DMF)

- [ ] В хабе: после «Mods reloaded.» ошибок мода нет.
- [ ] Посреди миссии: старые полосы и цифры исчезают, новые появляются, дублей нет.

## 6. Версия 0.2 (этап 1)

- [ ] Режим категории «Недавно раненые»: полоса появляется после урона и исчезает через N секунд (настройка), пока горит — видна.
- [ ] Режим «Только помеченные»: полоса только у врага с пингом отряда, снимается вместе с меткой.
- [ ] Дебаффы после значков урона: хрупкость (`40%`), получаемый урон (`+25%`), ближний бой / стрельба, ошеломление. Проверить таланты: хрупкость (огрин/ветеран), +урон (псайкер, зелот), благословение Thunderstrike / Skullcrusher. `/av_icons` — выбрать значки, сказать номера.
- [ ] Щит пустоты: голубая полоска над капитаном, пустеет при снятии щита; значки и имя не налезают.
- [ ] Прозрачность при прицеливании 30 %: при ADS полосы тускнеют, у врага в прицеле — яркая.
- [ ] Ослабленный / усиленный босс: другой цвет полосы, имя с приставкой как у полосы игры.

## 7. Совместимость

- [ ] С включённым Healthbars / Enemies Improved / DamageNumbers — предупреждение в чате при загрузке.
- [ ] RecolorBossHealthBars: не конфликтует со скрытием стандартной полосы босса.
